BreadCrumb options

Send to Obsidian

BreadCrumb appends a row per document to a Markdown table in one note in your vault. Pick the vault folder once: the browser asks you to allow access, and BreadCrumb can then read and write to that folder only. Nothing is sent anywhere; the note is written on this device.

Folders are created if they are missing, and .md is added if you leave it off. The note is created with the table the first time you send.

Use my SharePoint session

Lets the extension ask SharePoint where a linked file lives, using the Microsoft 365 session already open in this browser. Only SharePoint's answers are used; your session cookies are never read or sent anywhere. The browser will ask you to allow access to your tenant's SharePoint and OneDrive sites.

BreadCrumb can only confirm a file once this browser has a signed in session on the site. Open each one, sign in, then come back: · 


    

    

      
What BreadCrumb remembers

      
Every link you resolve is kept on this device, so a folder found once does not have to be found again. The newest two thousand are kept; older ones make way, and anything already written to your note is kept in preference. Nothing is sent anywhere, and removing the extension removes it all.
